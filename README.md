# WASCAN

## Project Description
WASCAN is a comprehensive web application security assessment tool designed to facilitate vulnerability analysis and enhance the security posture of web applications.

## Installation Instructions
1. Clone this repository:
   ```bash
   git clone https://github.com/benjaminbencsik/wascan.git
   ```
2. Navigate to the project directory:
   ```bash
   cd wascan
   ```
3. Install the required packages:
   ```bash
   npm install
   ```

## Use Cases
- Automated security scanning of web applications.
- Integration with CI/CD pipelines for continuous security assessments.
- Generating vulnerability reports for compliance auditing.

## Technical Specifications
- Developed using Node.js and Express.
- Utilizes OWASP ZAP for dynamic application security testing.
- Supports multiple authentication mechanisms.
